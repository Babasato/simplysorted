Filters configured

Auto-sorting rules

→Newsletter keywords (unsubscribe, digest) → Archive, skip inbox
→whitmoreco.com, hartleygroup.co.uk → Clients label
→Subject: invoice / receipt / order → Receipts label
→From: no-reply@* → Archive automatically
→Subject: ACTION or URGENT → Action Required + star
→LinkedIn notifications → Archive
→Google Alerts → Archive
