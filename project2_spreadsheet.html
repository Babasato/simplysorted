What changed

Improvements made

  • Consistent date format throughout (DD/MM/YYYY)
  • Proper description column — no more guesswork
  • Currency formatted with £ symbol and 2 decimal places
  • Standardised category names — no typos, no duplicates
  • Status column: Recurring / Reimbursable / Paid
  • Notes column for client attribution
  • Auto-filter enabled on all columns
  • Frozen header row — scrolls cleanly
  • Category summary with SUMIF formula
  • Running total formula — updates as you add rows
  • Colour-coded status tags for instant reading
