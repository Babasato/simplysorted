Keeping it sorted

5 rules to maintain the system

1
Always save files directly into the correct folder — never to the Drive root or your Desktop
2
Follow the naming convention for every new file, every time — no exceptions
3
At project end, move completed files into an Archive subfolder within the client folder
4
Delete duplicates immediately — the named file is the single source of truth
5
Do a 5-minute Drive review monthly — if anything is at root level, file it immediately
